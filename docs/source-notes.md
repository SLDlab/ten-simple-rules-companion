# Source notes

This documentation site was structured from the companion document titled **Ten simple rules for achieving computational reproducibility in cognitive neuroscience - Supporting Information [S1 Text]**.

The site keeps the source document's sequence, examples, terminology, and ten-rule organization. Conversion to Markdown required layout-only normalization of material that appeared in the PDF as page-oriented text, including:

- rebuilding directory trees as fenced text blocks;
- formatting commands, code, JSON, YAML, and Markdown examples as fenced code blocks;
- converting source tables to Markdown tables;
- rendering checklists as Markdown task lists; and
- separating the `uv add pandas numpy matplotlib` and `uv lock` commands, which appeared concatenated in the PDF text extraction.

No additional scientific claims or external guidance were added to the companion content. External URLs shown in the documentation are URLs that appear in the source draft.
